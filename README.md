# SP--twin · 가상 외래 공간 (WebXR)

SP 시뮬레이션 운영 발표용 3D 영상 도구입니다.
산부인과 외래 접수 → 대기석 → 처치실(소품 배치) → 시뮬레이션 밖(채혈채뇨실·초음파실) → 10분 진행 흐름(A~E)을
카메라가 자동으로 돌며 보여주고, 버튼 한 번으로 자막이 들어간 영상 파일로 저장합니다.

## 저장소에 들어 있어야 하는 파일 (3개)

| 파일 | 설명 |
| --- | --- |
| `index.html` | 장면, 자막, 카메라 순서, 녹화 기능이 모두 들어 있는 본체 |
| `three.min.js` | 3D 라이브러리(three.js). 인터넷 연결이 약해도 열리도록 같이 올립니다 |
| `README.md` | 이 안내문 |

## 1. GitHub에 올리기

1. 저장소(`SP--twin`) 첫 화면에서 **Add file → Upload files**
2. 위 파일 3개를 창에 끌어다 놓기
3. 아래 **Commit changes** 클릭

## 2. 웹 주소로 열 수 있게 하기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / `/ (root)` 선택 후 **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   예상 주소: `https://seonyoung101.github.io/SP--twin/`

> 파일을 더블클릭해서 바로 열면 브라우저 보안 때문에 장면이 안 뜰 수 있어요. 꼭 위 웹 주소로 여세요.

## 3. 영상으로 저장

1. 웹 주소를 **Chrome 또는 Edge**로 엽니다.
2. **● 영상으로 저장** 클릭 → 처음부터 자동 재생하며 녹화합니다 (약 1분 40초).
3. 끝나면 파일이 자동으로 내려받아집니다 (`SP-운영설계-가상외래.mp4`, 브라우저에 따라 `.webm`).
4. 녹화 중에는 **이 탭을 다른 탭으로 바꾸지 마세요.** 바꾸면 녹화가 취소됩니다.
5. 파일 용량이 부담되면 저장 후 휴대폰/PC 편집 앱(캡컷 등)에서 일부 구간만 잘라 쓰세요.
   `.webm`으로 저장됐다면 PowerPoint에서 안 열릴 수 있으니 mp4로 변환하세요.

## 4. VR(WebXR)로 보기

WebXR을 지원하는 헤드셋 브라우저(예: Meta Quest 브라우저)에서 웹 주소를 열고 **🥽 VR로 보기**를 누르세요.
컨트롤러 트리거를 누를 때마다 접수 → 대기석 → 처치실 입구 → 처치실 안 → 복도 순서로 이동합니다.
PC 브라우저에서는 버튼이 "VR 미지원"으로 표시됩니다(정상입니다).

## 5. 단축키

`Space` 재생/일시정지 · `←` `→` 5초 이동 · `1`~`8` 챕터 이동

## 6. 내용 고치기

`index.html`을 열어 `const SHOTS = [` 부분을 찾으세요. 한 장면(shot)이 다음 항목으로 되어 있습니다.

- `dur`: 장면 길이(초)
- `title` / `lines`: 화면 아래 자막 제목과 본문
- `cue`: 노란 "진행자 큐" 상자 문구
- `bp`: 우상단 혈압계 표시값 (`bpAlert: true`면 빨간색)
- `from` / `to`: 카메라 시작·끝 위치 (`[x, y, z, 바라보는 x, y, z]`)

문구만 바꿔도 되고, 장면 길이를 줄여 영상을 더 짧게 만들 수도 있습니다.

## 주의

- 저장소가 **공개(public)** 상태면 누구나 내용을 볼 수 있습니다. 장면에는 시나리오 요약(혈압 수치, 단계별 큐)이 들어 있으니, 발표 후 비공개로 돌리려면 Pages도 함께 꺼지는 점을 기억하세요.
- 환자 이름은 화면에 넣지 않았습니다.
- VR 모드는 실제 헤드셋에서 검증하지 못했습니다. PC에서의 재생·녹화는 확인했습니다.
